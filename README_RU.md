# Oxide iOS — UI-only overlay starter

Это демонстрационный UIKit-оверлей для iOS. Он **не является готовым читом** и не меняет игровой процесс.

## Что исправлено
- `Tweak.xm` пытается прикрепить оверлей к активному окну приложения.
- `OverlayMenu.m` содержит перетаскиваемую панель с демонстрационными переключателями.
- Область вне панели пропускает касания в приложение.
- Переключатели только выводят состояние в журнал; чтения/изменения памяти, игровых хуков, автоматизации и обхода античита нет.

## Сборка
GitHub Actions запускает Theos на macOS и публикует собранный пакет как workflow artifact. Это пакет tweak (`.deb`), **не подписанный IPA**. Чтобы встроить библиотеку в конкретную сборку Oxide и проверить совместимость, нужен соответствующий IPA и отдельная процедура установки/подписи. Успешная компиляция сама по себе не доказывает, что меню заработает в игре.

## Где посмотреть результат
Откройте вкладку **Actions**, выберите workflow **Build iOS tweak template**, затем последний запуск и скачайте artifact `oxide-overlay-template-package`, если сборка завершилась успешно.
