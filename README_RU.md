# Oxide iOS — стартовый шаблон меню

Это **исходный шаблон UI**, не готовая `.dylib` и не IPA. Переключатели ESP / Aim / Farm демонстрационные и не воздействуют на игру.

## Файлы
- `OverlayMenu.m` — пример UIKit-панели с переключателями.
- `Tweak.xm` — безопасная точка входа без игровых хуков и чтения/изменения памяти.
- `Makefile` — базовый шаблон Theos.
- `control` — метаданные пакета.

## Сборка
Для сборки нужен совместимый Theos toolchain и iOS SDK. Этот репозиторий пока не содержит готового бинарника. Даже успешная компиляция шаблона не означает, что меню автоматически появится внутри Oxide: интеграция UI не настроена.

Не загружайте непроверенные библиотеки в основную игровую учётную запись.
